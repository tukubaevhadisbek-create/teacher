# Панель преподавателя (Online Coaching Teacher's Admin Panel)

Учебный проект на Django: панель преподавателя по макету Figma. Весь интерфейс на русском языке.
Одно приложение `main`, база SQLite, только HTML и CSS. **JavaScript в проекте нет.**

## Что умеет

- **Главная**: статистика из базы (курсы, студенты, предстоящие занятия, открытые задачи), занятия, задачи с фильтром по статусу, группы.
- **Онлайн-занятия**: создание, правка, удаление, ссылка на Zoom/Meet, история, отметка посещаемости, поиск.
- **Расписание**: канбан-доска задач и недельная сетка занятий, тестов, экзаменов и заданий (переключение недель).
- **Тесты, экзамены, задания**: пошаговое создание (мастер), правка, удаление, ввод результатов и оценок, поиск, вкладки «Предстоящие» и «История».
- **Банк вопросов и теги**; PDF-файлы к заданиям.
- **Группы**, **курсы** (с предметами по семестрам), **студенты** (поиск, фильтр по курсу и группе, профиль с успеваемостью).
- **Мой профиль** и **Настройки** (смена пароля).
- **API** (Django REST Framework): `/api/`, адреса создаёт роутер в `main/urls.py`.

Каждый преподаватель видит только свои данные. Выход из аккаунта и удаление записей выполняются только POST-запросом.

## Установка на Windows

Откройте PowerShell в папке проекта (где лежит `manage.py`):

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ и войдите созданным логином. Через http://127.0.0.1:8000/admin/ можно создавать других преподавателей.

### Демо-данные (по желанию)

```powershell
python manage.py seed_demo
```

Создаст преподавателей `ainura` (пароль `ainura123`) и `bakyt` (пароль `bakyt12345`) с курсом, группами, занятиями, тестами и студентами.
Пароли демо-пользователей нужны только для учебы, на настоящем сервере их не используйте.

### Проверка

```powershell
python manage.py check
python manage.py test
```

## Устройство проекта

```
config/              настройки проекта (settings.py, urls.py)
main/
  models.py          таблицы базы данных
  forms.py           формы и их проверки
  views.py           страницы (функции) и API (ViewSet)
  serializers.py     сериализаторы для API
  urls.py            адреса страниц и роутер API
  tests.py           автоматические тесты
  templates/main/    HTML-шаблоны (все наследуют base.html)
  static/main/css/   style.css
```

Как это работает: адрес из `urls.py` вызывает функцию из `views.py`. Она берёт данные через ORM из `models.py`, проверяет формы из `forms.py` и показывает шаблон из `templates/main/`.
В каждом запросе стоит фильтр `teacher=request.user`, поэтому чужие записи недоступны (вместо них сайт отвечает «Страница не найдена»).

## Что стоит знать

- Поиск по русскому тексту выполняется в Python (`search_filter` в `views.py`), потому что SQLite не различает регистр у кириллицы. Для небольшого проекта этого достаточно.
- Курс может быть общим (без владельца, его создаёт администратор): преподаватель видит его, если у него там есть группа, но менять и удалять не может.
- Для настоящего сервера нужно задать собственный `SECRET_KEY`, `DEBUG = False` и `ALLOWED_HOSTS` в `config/settings.py`.
